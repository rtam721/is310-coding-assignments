## Music Artist Collaborations and Data Entry

## About 
For my assignment, I chose to create a data table that includes data on music collaborations between artists. It includes the artist, song title, collaborating artist, year it released, song genre, artist genre theat they're generally known for, and the collaborators genre that they're known for. 

## Requirements
This requires  Python 3 and the Rich Library

To install the requirements:

    pip install -r requirements.txt

## How To Run The CLI

To run it, you can type 

    python3 cli_data_entry.py

in the terminal. This will allow users to enter in data of music collaborations they would like to include. After confirming that it's all good, it saves it into a csv file.



## Comparison between each interface 
I would say that they're both pretty easy to view since they're in a table format. I will admit that the HTML webpage format is easier to interact with though since it shows eveything right there and you can choose what text entry you want to type in. However for the CLI, you have to answer each question/entry that pops up individually so you can't just change to answer out of order.

## Did the interfaces lead you to make different choices about fields, instructions, or validation?

I would say the interfaces did not lead me to change the fields because I wanted both to collect the same data. Though they both collect data in different ways. The CLI asks users to confirm the information before saving it but HTML has required fields for users to make sure the fields are filled out before the users submit it.
